## ⚡️ 3분 빠른 시작 (Quick Start)

```
[1. 앱 실행] ──▶ [2. 상단 '직업 프리셋 적용' 선택] ──▶ [3. 게임 화면에서 시작키('[') 입력]
```

1. **앱 실행 후 권한 허용**: `시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용`에서 허용
2. **원클릭 직업 프리셋 적용**:
   - 상단바 드롭다운에서 **악마술사(타오르는 비명)**, **원소술사**, **야만용사**, **도적** 등 선택
3. **게임 화면에서 시작**:
   - `[` (대괄호 열기) 키를 누르면 오프너(버프/스택) 시퀀스 후 메인 전투 루프가 자동 실행됩니다.

| ⚔️ **야만용사**<br/>(소용돌이 채널링) | **3함성 분노 폭발 & 소용돌이 지속 회전(홀드)** | • **오프너**: 집결/도전/전장 3함성 순차 시전<br/>• **본 루프**: 3함성 쿨마다 유지 + **우클릭(소용돌이) [홀드(누름)] 모드** |
| 🏹 **도적**<br/>(3콤보 포인트) | **3연계 점수(구멍 뚫기 3회) → 회전 칼날 1회 교대** | • **오프너**: 암흑 주입 → 그림자 걸음 진입<br/>• **콤보 루프**: 생성기(3번) 3회 ↔ 소모기(우클릭) 1회 자동 교대 |
| 💀 **강령술사**<br/>(시폭 & 뼈창) | **골렘/저주 군중제어 & 시폭/뼈창 폭딜** | • **오프너**: 골렘 활성화 → 노화 저주 살포 → 시체 촉수<br/>• **본 루프**: 뼈창(200ms) + 시체 폭발(120ms) 고속 연타 |
| 🦅 **혼령사**<br/>(태세 & 제압) | **태세 버프 & 결의 스택 제압 사이클** | • **오프너**: 태세 버프 → 결의 스택 누적<br/>• **콤보 루프**: 깃털 투척 3회 ↔ 제압기 1회 교대 |

## 💎 주요 기능 및 3-탭 화면 구성

### 탭 1: 기본 헬퍼
<p align="center">
  <img src="03_screen_tab1.png?raw=true" alt="탭 1: 기본 헬퍼" width="850"/>
</p>

- **시작/종료키 & 준비 키(오프너)**: 원클릭 토글(`[`) 또는 분리 가능하며, 메인 화면에서 바로 오프너 단축키와 사용 여부를 원터치 설정 가능
- **기술 1~8번 슬롯**: 키보드 및 마우스 휠(Up/Down), 미들 클릭, 사이드 버튼(XButton 1/2) 등록 지원
- **시전 방식 (연타 Spam vs 홀드 Hold)**:
  - 일반 스킬은 빠른 연타, 지속 스킬(소용돌이, 소각 등)은 누르고 있는 **홀드 모드** 지원

### 🌐 구글 시트 프리셋 공유 센터 (`[ 🌐 시트 공유 ]`)
- **실시간 클라우드 프리셋 조회**: 유저별, 시즌별(시즌 6, 7, 영원 등), 직업/빌드별 공인 세팅 실시간 검색
- **원클릭 가져오기**: 원하는 빌드를 선택하고 슬롯(1~5)을 골라 즉시 내 헬퍼에 로드
- **내 빌드 공유 & 행 복사**: 내가 완성한 세팅을 구글 시트에 원클릭 공유하거나 `Cmd+V`용 TSV 행 데이터 복사
- **길드/클랜 전용 시트 연동**: 개인 또는 클랜 비공개 구글 시트 URL 및 Apps Script Web App 연동 지원

### 탭 2: 로테이션 & 준비 시퀀스
<p align="center">
  <img src="03_screen_tab2.png?raw=true" alt="탭 2: 로테이션 & 준비 시퀀스" width="850"/>
</p>

- **초기 준비 시퀀스 (Opener & Ramp-up)**:
  - 시작 시(또는 수동 F1/상단 `⚡️ 준비 시퀀스` 버튼) 최대 5단계의 버프/스택 스킬을 순차 실행 후 본 루프로 자동 전환
- **스킬 연계 콤보 사이클 (Generator-to-Spender)**:
  - 생성기 A를 N회 타격 후 소모기 B를 M회 시전하는 정밀 교대 타이머 (예: 도적 3:1)

### 탭 3: 단일반복 & 편의기능
<p align="center">
  <img src="03_screen_tab3.png?raw=true" alt="탭 3: 단일반복 & 편의기능" width="850"/>
</p>

- **단일반복키 (독립 루프)**:
  - `~` (Grave): 50ms 마우스 좌클릭 (바닥 아이템 자동 폭풍 줍기)
  - `Tab`: 60ms 마우스 우클릭 (카달라/상점 대량 겜블)
- **특수키 (최대 3개)**: 누르고 있는 동안 체크된 스킬 일시정지 & 쿨타임 대기 제어
- **퀘스트키**: NPC 대화 및 상호작용 시 모든 스킬 전면 일시정지
- **시간조절키**: 도관/쿨감 신단 획득 시 1회 눌러 전체 주기 가속
- **방해금지 데드존**: 하단 스킬바, 자원 구슬 오클릭 자동 방지

### 🌐 한국어 & 영어 완벽 다국어 지원 (Bilingual Support: KO / EN)
- **실시간 원클릭 언어 전환**: 상단 제어 바의 언어 팝업(`🌐 KO` / `🌐 EN` / `🌐 Auto`) 또는 macOS 메뉴바(Status Item)에서 실시간 원클릭 전환
- **편집 상태 100% 무손실 보존**: 언어를 전환해도 입력 중이던 키 매핑, 딜레이(ms), 메모, 체크박스 상태가 즉시 그대로 보존
- **전체 화면 완벽 번역**:
  - 메인 창 (상단 제어 바, 3개 탭의 모든 박스, 라벨, 툴팁, 가이드 노트)
  - 인앱 설명서 가이드 창 (5개 카테고리 전체 한/영 듀얼 HTML 가이드)
  - 구글 시트 프리셋 공유 센터 및 직업 프리셋명 영문화 (`Warlock`, `Sorcerer`, `Barbarian`, `Rogue`, `Necromancer`, `Spiritborn`)
- **시스템 언어 자동 감지**: 영문 macOS 환경에서는 영어로 자동 시작, 한글 환경에서는 한국어로 자동 시작

## ❓ 문제 해결

**손쉬운 사용에 체크가 되어 있는데도 동작하지 않는 경우** (macOS Sequoia 15.6+ / Tahoe 26)
- macOS 업데이트나 앱 파일 교체 후에는 권한이 풀릴 수 있습니다.
- **시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용**에서 앱을 목록에서 **제거(-)** 한 뒤 **다시 추가(+)** 해주세요.

**시작키를 눌러도 반응이 없는 경우**
- 게임이 최전면인 상태에서 시작키를 눌렀는지 확인해주세요. (게임 화면에만 키를 발송하여 외부 유출 방지)

- **단일반복키 & 편의기능(3번 탭) 안정화**:
  - 토글키가 임의의 키(`~`, `Tab`)로 덮어써지거나 초기화되던 현상 원천 차단
  - 마우스 좌클릭 유입 시 포커스 해제 및 키 롤백 버그 수정
  - 사용자가 비워둔 키와 커스텀 키 설정 100% 영구 보존
- **인앱 도움말 가이드 창 탑재 (`Cmd + ?`)**:
  - 라이트 모드 / 다크 모드 완벽 대응하는 미려한 내장 매뉴얼 뷰어 (한/영 듀얼 탭 지원)

### 1.4 (DHelper 에디션 전면 개편)
- DHelper 기준 2단 그리드 UI 전면 재설계 (창 크기 880x680 최적화)
- 저수준 `CGEventTap` 기반 정밀 입력 엔진 구축 (KeyUp, 마우스 휠, 사이드 버튼 지원)
- GCD `dispatch_source_t` 기반 고성능 타이머 엔진(`D3HelperEngine`)
- 디아블로 4 전 직업 원클릭 프리셋 및 오프너/콤보 메커니즘 추가
- 프로필 파일(.dhp / .json) 저장 및 불러오기 기능 추가
