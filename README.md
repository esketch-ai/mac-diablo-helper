# D3/D4 Skill Assistant

> 이 프로젝트는 [sunghyuk/D3-Skill-Assistant](https://github.com/sunghyuk/D3-Skill-Assistant)에서
> 기원한 포크입니다. 원작자 sunghyuk님과 기여자분들께 감사드립니다.
> macOS Sequoia 15.6+ 대응과 디아블로4(GPTK) 지원을 위해 이어서 관리하고 있습니다.
> 원본과 동일하게 [Apache License 2.0](LICENSE)을 따릅니다.

맥용 디아블로3 / 디아블로4 헬퍼 프로그램입니다.
설정한 키를 정해진 간격으로 자동 입력해줍니다.

윈도용 헬퍼 프로그램 소개페이지만 참고해서 만든 것이라 다르게 동작할 수 있습니다.

## 지원 환경

- macOS 10.13 (High Sierra) 이상, Apple Silicon / Intel 유니버설
- **디아블로3**: 맥 네이티브 클라이언트
- **디아블로4**: 맥 네이티브 버전은 없지만 Game Porting Toolkit(GPTK), CrossOver, Whisky 등으로 실행하는 경우 동작합니다

## 설치 및 권한 설정

키보드 이벤트를 감지하고 발송하려면 손쉬운 사용 권한이 필요합니다.

1. 앱을 실행하면 권한 요청 안내가 표시됩니다.

![권한 요청 안내](01_D3D4%20allow.png?raw=true)

2. **시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용**에서 앱을 허용해주세요.

![손쉬운 사용 허용](02_optio%20on.png?raw=true)

3. 허용하면 앱이 자동으로 활성화됩니다. (재시작 불필요)

## 사용 방법

1. 설정 화면에서 시작키/종료키, 스킬 키와 딜레이(ms)를 지정합니다.
2. **게임을 최전면에 둔 상태에서** 시작키를 누르면 자동 입력이 시작됩니다.
   시작키를 누른 시점의 최전면 앱이 대상으로 고정되므로, 반드시 게임 화면에서 눌러주세요.
3. 다른 앱으로 전환하면 키 발송이 자동으로 멈추고, 게임으로 돌아오면 재개됩니다.
4. 종료키를 누르면 자동 입력이 중단됩니다.
5. F1~F5 키로 프리셋(설정 1~5)을 전환할 수 있고, 프리셋마다 메모를 남길 수 있습니다.

![설정](03_screen.png?raw=true)

## 문제 해결

**손쉬운 사용에 체크가 되어 있는데도 동작하지 않는 경우** (macOS Sequoia 15.6+ / Tahoe 26)

macOS 업데이트나 앱 파일 교체 후에는 권한이 풀릴 수 있습니다.

1. **시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용**에서 앱을 목록에서 **제거(-)** 한 뒤 **다시 추가(+)** 해주세요.
2. 앱을 재실행하세요.

**시작키를 눌러도 반응이 없는 경우**

- 게임이 아닌 다른 앱이 최전면인 상태에서 시작키를 눌렀는지 확인해주세요. (1.3부터는 시작 시점의 최전면 앱에만 키를 보냅니다)

## 변경사항

- 손쉬운 사용 권한을 나중에 허용해도 앱 재시작 없이 자동 활성화
- 권한이 없을 때 앱이 강제 종료되던 동작 제거
- Apple Silicon(arm64) + Intel(x86_64) 유니버설 빌드
